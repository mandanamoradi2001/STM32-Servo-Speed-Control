# STM32-Servo-Speed-Control
In this project I have programmed an STM32 connected to an HC-05 module to receive data from a mobile phone via an app that can be downloaded from playstore and change the speed a servo motor rotates.
As an additional way to send the inputs, I also programmed it to receive the same input via a USB-TTL module from a PC and behave the same way. 
The state of the system will be displayed on an LCD.
